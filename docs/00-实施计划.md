# 实施计划

用户已审核通过迁移路线，先完成一个仿真工程基线，再研究创新。

1. 复用 Isaac Lab / SONIC，新建 G1 两指夹爪场景，验证站立、腕部跟踪、开合和接触。
2. 右手将桌面彩色方块放进宽托盘。先用真值诊断接口，再以 RGB-D 视觉反馈运行固定抓放策略，目标固定场景至少 8/10 成功。
3. 从同一观测生成五个可执行候选，验证物理状态与控制历史的一致起点。候选 0 为默认策略；先检查 20 个锚点的 100 个分支。
4. 采集新数据，先以约 200 个锚点试运行，再按需要扩展。冻结编码器和 SONIC，训练 EmbodiedSkills 三个后果模型及原比较头。按完整回合划分数据。
5. 在 30 个预留初始条件上配对比较直接、随机和 EmbodiedSkills。交付完整抓放视频、在线成功率、失败分析和复现入口。

本轮上层采用固定视觉抓放规划策略，验证完整预测选择框架；后续 VLA 可替换同一候选接口。旧实验仅参考接入经验，重新构建任务、采集和评测。

正式执行保持浮动基座与物理接触，物体通过夹爪摩擦抓持。每个执行段后重新观察。在线选择不读取未来分支标签；用于训练的分支离线执行并标注。

每阶段在 `docs/` 写实测结论，在 `LOG.md` 记时间、内容与状态，使用中文 commit 推送 GitHub。生成的大型数据、权重与视频保留本机 `outputs/`。
