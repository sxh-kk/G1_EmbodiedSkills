# 阶段 1：夹爪与控制接口验收

时间：2026-10-14 21:44–21:48（北京时间）。结论：身体控制、夹爪开合及小幅腕部运动的接口验收通过，进入直接抓放调试。

## 实验

从 SONIC 原 G1 URDF 在本机生成夹爪变体：移除右侧固定手，增加质量合计 0.23 kg 的两指夹爪。保留 29 个身体关节及原动作顺序，另增加两个直线关节。冻结 SONIC release 权重，没有重新训练身体控制器。机器人保持浮动基座，未固定双脚。

物理步长 0.005 秒，控制周期 0.02 秒。实际身体动作 29 维，策略历史输入 930 维。G1 编码器的未来参考为当前至 0.9 秒、间隔 0.1 秒的 10 帧，后续候选编码必须保留这些实际消费的预览。

正式接口实验包含站立参考和小幅腕部运动参考，每组重复 3 次，每次 8 秒；2–4 秒指令闭合夹爪，其余时间张开。参考由新代码和官方 FK 重新生成。另有一次单回合开发检查，不计入六次正式结果。

## 结果

- 六次运行均完成 400 个控制步，没有触发终止；站立和夹爪开合均 6/6 通过。
- 六次最低 root 高度约 0.75293 m；最大倾角 0.01696 rad，最大水平漂移 0.01597 m。
- 闭合稳定区间内，夹爪单侧关节最大残余开度不超过 0.000181 m；重新张开后最小开度大于 0.03436 m，目标为 0.035 m。
- 站立参考下 TCP 对原始世界参考的平均误差约 3.29 cm；小幅腕部运动参考下约 2.72 cm，最大约 3.40 cm。

原始世界参考误差包含身体整体漂移，不等同于纯关节跟踪误差。这个量级仍足以影响 35 mm 方块抓取，因此阶段 2 必须检查末端定位并加入反馈，不能据六次站立成功推断抓取已可靠。

小体积实际指标与接口字段见 [metrics/stage1.json](metrics/stage1.json)。完整轨迹位于本机 `outputs/stage1/standing` 与 `outputs/stage1/wrist-motion`，不纳入 Git。当前尚未测试物体夹持、抬升、视觉定位和完整任务成功率。

## 复现

先按 README 设置现有环境路径，使用同一环境的普通 Python 准备参考，再用 Isaac 启动包装器运行：

```bash
python scripts/build_asset.py --output outputs/assets
python scripts/prepare_reference.py --output outputs/references --duration 20
bash "$ISAAC_PYTHON" scripts/run_sim.py \
  --reference outputs/references/standing \
  --asset outputs/assets/g1_parallel_gripper.urdf \
  --output outputs/stage1/standing --seconds 8 --repeats 3
bash "$ISAAC_PYTHON" scripts/run_sim.py \
  --reference outputs/references/wrist_motion \
  --asset outputs/assets/g1_parallel_gripper.urdf \
  --output outputs/stage1/wrist-motion --seconds 8 --repeats 3
```

输出目录必须不存在，避免覆盖实验记录。首次启动曾因现有 Isaac 包装器清空 PYTHONPATH 而失败；入口现已在启动前显式加入本项目源码路径，随后六次正式运行使用修正后的入口。
