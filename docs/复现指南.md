## 分支采集与审核

```bash
"$PYTHON" scripts/collect_dataset.py \
  --isaac-python "$ISAAC_PYTHON" --sonic "$SONIC_ROOT" \
  --reference outputs/task-pilot-v1/native \
  --asset outputs/assets/g1_parallel_gripper.urdf \
  --configs configs/collection-formal-phase-{0..4}.json \
  --num-envs 20 --output outputs/stage4/dataset

"$PYTHON" scripts/summarize_collection.py \
  --collections outputs/stage4/dataset/shard-{00..04}/collection \
  --require-object-gate --output outputs/stage4/formal-verified.npz \
  --report outputs/stage4/formal-verified.json
```

每个锚点的五分支使用同一物理槽位和实际控制前缀。原生参考、夹爪指令和底层动作均重放；重建物理后检查身体、物体完整状态与控制历史，超出绝对容差 `1e-3` 的整组剔除。不会通过放宽检查来凑足计划数量。每个分片使用新进程，限制相机重建的资源积累；显存采样保存在 `resources.jsonl`。

动作编码为 `[5,75,38]`：29 身体关节、3 根位置、4 WXYZ 根四元数、2 夹爪关节。75 帧是 SONIC 预览与滤波所需参考窗口；实际每次执行 10 个控制步，即 0.2 秒。未来图像在执行段结束时采集，成功及回报由同一直接策略续行至 24 秒后标注。

## 特征与训练

需预先缓存以下冻结模型的指定版本：V-JEPA2 `facebook/vjepa2-vitl-fpc64-256@b3c1679b7c34d3255ef3547f27c7b226aefab26f`、MiniLM `sentence-transformers/all-MiniLM-L6-v2@1110a243fdf4706b3f48f1d95db1a4f5529b4d41`。本机已有所需文件；提取及在线加载均为离线模式。

```bash
"$PYTHON" scripts/train_selector.py extract \
  --input outputs/stage4/formal-verified.npz \
  --output outputs/stage4/formal-features.npz --device cuda --batch-size 16

"$PYTHON" scripts/train_selector.py split \
  --input outputs/stage4/formal-features.npz \
  --output-dir outputs/stage4/splits \
  --validation-fraction .15 --test-fraction .15 --seed 42

"$PYTHON" scripts/train_selector.py train \
  --train outputs/stage4/splits/train.npz \
  --validation outputs/stage4/splits/validation.npz \
  --config configs/training.yaml --output outputs/stage4/selector --device cuda
```

使用原连续动作模型、3 个成员、30 轮成员训练及 40 轮比较头训练，不更改原损失或验证选模。1041 维状态不包含物块真值；语言为当前固定任务指令，真实冻结编码向量随 bundle 缓存，保证训练和在线逐位一致。当前任务不支持未见指令的语言泛化。

## 在线选择

```bash
bash "$ISAAC_PYTHON" scripts/run_sim.py \
  --reference outputs/task-pilot-v1/native \
  --asset outputs/assets/g1_parallel_gripper.urdf \
  --embodiedskills-root "$EMBODIEDSKILLS_ROOT" \
  --selector outputs/stage4/selector/selector.pt \
  --output outputs/selector-demo --mode closed_loop --method selector \
  --seconds 24 --cameras --position-jitter .02 --amplitude-m .025 \
  --seed-base 900000 --repeats 1 --record-video
```

配对评测配置在 `configs/evaluation.json`：三种方法分别使用相同 30 个新种子、8 个物理槽位、24 秒预算。直接和随机方法分别使用 `--method direct` 或 `--method random`，不需加载 selector。正式评测中，选择器使用真实三个后果模型和比较头分数决定编号，每段执行后重新观察，不读取离线分支标签。
